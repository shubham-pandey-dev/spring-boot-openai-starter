# Spring Boot + OpenAI Integration

A simple Spring Boot application demonstrating integration with the OpenAI API using Spring AI.

## Tech Stack

- Java
- Spring Boot
- Spring AI
- Maven
- OpenAI API

## Prerequisites

- Java (version required by the project)
- Maven (or use the included Maven wrapper)
- OpenAI API key

## Configuration

1. Clone the repository.
2. Create a `.env` file in the project root.
3. Add your OpenAI API key:

```properties
OPENAI_API_KEY=your-openai-api-key
```

## Running the Application

Run using Maven:

```bash
./mvnw spring-boot:run
```

On Windows:

```powershell
.\mvnw.cmd spring-boot:run
```

## Purpose

This project is a starting point for exploring Spring Boot application development and integrating LLM capabilities using OpenAI APIs.
